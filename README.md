# SPX-Volatility-Forecasting-using-Deep-Learning
This is an engineering school project in deep learning and quantitative finance. The goal was to forecast S&amp;P 500 21-day realized volatility using SPX and VIX data from Yahoo Finance. It compares baseline models (Naive, HAR) with deep learning architectures (MLP) evaluated via RMSE, MAE, and QLIKE metrics.
