# SPX-Volatility-Forecasting-using-Deep-Learning
This is an engineering school project in quantitative finance and deep learning. The goal was to forecast the next-day realized volatility of the S&P 500 over a 21-day horizon. I have worked on historical daily data of the S&P 500 and the VIX index collected from Yahoo Finance. The notebook implements benchmark models (Naive baseline and HAR-RV linear regression) as well as deep learning architectures (such as MLP) evaluated using RMSE, MAE, and QLIKE loss metrics. All details and source code are available directly in the notebook.
